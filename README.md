# SQL-Music-Project
Samostalni Oracle SQL projekt u kojem ocjenjujem svoje najdraže pjesme i muzičare te uspoređujem i kalkuliram rezultate na različite načine.
Razdvojio sam projekt na 4 dijela kako bi lakše bilo unijeti kod u druge programske jezike, te sam ostavio originalni projekt da se vidi na koji način sam postigao ove rezultate.
